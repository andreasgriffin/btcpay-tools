# BTCPay Subscription Tools

Public HTTP API for BTCPay subscription management. See
[btcpay_tools/btcpay_subscription_api/README.md](btcpay_tools/btcpay_subscription_api/README.md)
for configuration, endpoints, and deployment.

The status and plan catalog endpoints require the BTCPay API key permission
`btcpay.store.canviewofferings`, scoped to the store.
